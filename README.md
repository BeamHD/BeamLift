# Beam Lift

A personal, offline-first workout logger (installable PWA). Today's session is pre-loaded from the program,
each set is pre-filled from last time, ✓ starts the rest timer, and a one-tap check-in (effort + knee/shoulder/back
pain) drives the progression rules. Imports Hevy CSV exports. Data stays on the device; export JSON/CSV anytime.

No build step: serve the folder over HTTPS (GitHub Pages) and "Install app" from Chrome.
